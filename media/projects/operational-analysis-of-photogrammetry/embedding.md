Operational Analysis of Photogrammetry investigates photogrammetry as invisible infrastructure — in Google Maps, autonomous vehicles, surveillance. The thesis asks how algorithms actively construct spatial knowledge. Using Operational Analysis (Friedrich and Hoel, 2023) and Simondon's transduction theory, each pipeline step is examined: feature detection, image matching, pose estimation, point cloud construction, 3D reconstruction, SLAM, structure from motion, ORB-SLAM3.

The thesis has two outputs: a large printed operational map of the full algorithm pipeline, and an interactive installation built entirely in TouchDesigner. TouchDesigner is the sole real-time programming environment used. CHOP, TOP, DAT, operator network, node-based visual programming, parameter interface, MIDI controller, live camera feed, keypoint detection visualization, real-time feedback.

The physical installation: aluminium truss tower, silver scaffolding, multiple monitors, neon green interface on black, data visualization, parameter dials, numerical readouts. Tools: TouchDesigner, Python, Metashape, ORB-SLAM3.
