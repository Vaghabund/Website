Operational Analysis of Photogrammetry. Master thesis, 2025, UdK Berlin and TU Berlin. Academic research, algorithmic analysis, critical systems design, software studies.

Photogrammetry — 3D space reconstruction from photographs — constitutes invisible infrastructure in Google Maps, autonomous vehicles, and surveillance. This thesis doesn't ask what photogrammetry produces, but how algorithms actively construct spatial knowledge. Using Operational Analysis (Friedrich & Hoel, 2023), each computational step is examined as an interdependent network: feature detection, image matching, pose estimation, point cloud construction. Each moment restructures conditions for the next.

Early parameter decisions cascade through the pipeline. Corner detection thresholds, matching tolerances, point cloud size limits encode assumptions about valid spatial information — presented as objective but inherently value-laden. The research exposes these embedded values through two complementary outputs: an operational map visualizing the full pipeline spatially, and an interactive TouchDesigner installation implementing ORB-SLAM3 (Structure-from-Motion algorithm). Users adjust parameters and immediately observe cascading effects, transforming photogrammetry from opaque black box into interrogable system.

Theoretical grounding: Gilbert Simondon on transduction. Tools: TouchDesigner, Python, ORB-SLAM3, Metashape, SfM. Keywords: computer vision, 3D reconstruction, algorithms, SLAM, point cloud, algorithmic opacity, parameter cascades, black box, critical systems, media theory, software studies, operational mapping, Simondon.
