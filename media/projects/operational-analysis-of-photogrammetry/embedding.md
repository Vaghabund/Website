Tools: TouchDesigner, Python, Metashape, ORB-SLAM3. Not Blender, not Cinema4D

Master thesis, MA, graduation project at Universität der Künste Berlin and TU Berlin, 2025. Tracing the Transductive. Academic research, written thesis, installation.

Photogrammetry is the reconstruction of 3D space from overlapping photographs. It is invisible infrastructure embedded in Google Maps, autonomous navigation, and biometric surveillance. This master thesis opens the black box of algorithmic image processing — not asking what photogrammetry produces, but how it actively constructs spatial knowledge. The research develops a systematic method for mapping photogrammetry's internal mechanisms and exposing the values embedded in its operations.

Using Operational Analysis (Friedrich and Hoel, 2023), each algorithmic step is examined as part of an interdependent network: feature detection, image matching, pose estimation, point cloud construction. Each operative moment restructures conditions for the next. Early parameter decisions cascade through the entire pipeline. Corner detection thresholds, matching tolerances, point cloud size limits — these choices encode specific assumptions about what counts as valid spatial information, yet are presented as objective and inevitable.

The work includes an operational map visualizing the full pipeline spatially, and a working installation built in TouchDesigner implementing ORB-SLAM3, a Structure-from-Motion algorithm. Users can adjust parameters and immediately observe how changes cascade through the pipeline, transforming photogrammetry from opaque black box into an interrogable system.

Theoretical grounding draws on Gilbert Simondon's concept of transduction. Tools: TouchDesigner, Python, Metashape, ORB-SLAM3, SfM. Keywords: computer vision, 3D reconstruction, algorithms, point cloud, SfM, SLAM, algorithmic opacity, critical theory, media theory, software studies, UdK Berlin.
