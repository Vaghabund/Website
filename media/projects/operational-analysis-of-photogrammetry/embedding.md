Operational Analysis of Photogrammetry. Master thesis, 2025, Universität der Künste Berlin and TU Berlin. Academic research, critical theory, interactive installation, software studies, media theory.

This is a master thesis — graduate research, dissertation, university project, academic work. The thesis investigates photogrammetry, the computational reconstruction of 3D space from overlapping photographs, as invisible infrastructure embedded in Google Maps, autonomous vehicles, and surveillance systems. The research asks not what photogrammetry produces, but how its algorithms actively construct spatial knowledge through a network of interdependent choices.

Using Operational Analysis (Friedrich and Hoel, 2023) and Gilbert Simondon's theory of transduction, each step of the photogrammetric pipeline is examined: feature detection, image matching, pose estimation, point cloud construction. Early parameter decisions cascade through the pipeline. Corner detection thresholds, matching tolerances, and point cloud size limits encode assumptions about valid spatial information, presented as objective but inherently value-laden. The thesis exposes these embedded values and opens the black box.

Two outputs: a large printed operational map visualizing the full algorithm pipeline spatially, and an interactive installation built entirely in TouchDesigner. TouchDesigner is the core tool — the entire real-time system, the parameter interface, the live camera feed, the keypoint visualization, and the MIDI controller integration are all wired in TouchDesigner. Visitors adjust parameters via a MIDI controller and observe cascading effects in real time on multiple screens. TouchDesigner, node-based programming, real-time visual system, CHOP, TOP, DAT, operator network.

The physical installation is a freestanding aluminium truss tower, silver metal scaffolding, with multiple monitors mounted at different angles. The interface is neon green on black — dials, numerical readouts, live keypoint detection rings visualized as glowing green circles. Color palette: silver aluminium, matte black, neon green. One version in bright white daylit studio, one in dark exhibition room with glowing screens. The structure is technical, industrial, scaffolding-like. A camera sits atop the truss.

Tools: TouchDesigner, TouchDesigner, Python, ORB-SLAM3, Metashape, SfM.
