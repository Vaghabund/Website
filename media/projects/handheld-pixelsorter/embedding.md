A portable, self-contained kiosk device for creating glitch art through real-time pixel sorting. Built on a Raspberry Pi 5 with a 7-inch HDMI touchscreen and a Raspberry Pi Camera Module 3. No laptop required, no app, no desktop environment — boots directly into the sorting interface. Optional UPS HAT for battery-powered standalone operation. 3D-printable enclosure.

The software is written entirely in Rust using egui as the UI framework. Cross-compiled for the Raspberry Pi using the Cross tool. Deployed as a systemd service. The application covers hardware integration, image capture, image processing algorithms, session management, USB export, and kiosk auto-sleep.

The pixel sorting workflow: capture a photograph or import an image, select a sorting direction (horizontal, vertical, diagonal), adjust a threshold slider to control where pixel segments break, optionally apply hue tinting, crop the result, and save to a connected USB drive. The output can be fed back as new input for deeper, iterative fragmentation — layering glitch effects across multiple passes.

The aesthetic is fragmentation, structured noise, deliberate visual corruption. Reordering pixels by brightness or hue. Algorithmic photography. Glitch photography. Databending.
