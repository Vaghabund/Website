A Cinema 4D plugin that automates synthetic COLMAP dataset generation for Gaussian Splatting reconstruction. Outputs camera rigs, rendered image sequences, sparse point clouds, and camera pose JSON from within Cinema 4D with no manual reformatting required. Includes surface normal visibility filtering to exclude backfacing geometry. Available for free on GitHub, Gumroad, and directly from this site.

Built in Python using the Cinema 4D Python SDK. Covers camera model mathematics, COLMAP file format implementation, and plugin architecture. Designed for rapid prototyping of Gaussian Splat reconstructions on controlled synthetic geometry, bypassing physical photo capture entirely.
