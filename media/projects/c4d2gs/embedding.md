C4D2GS is a free Cinema 4D plugin from 2026 that bridges 3D scene authoring and Gaussian Splatting reconstruction. It generates synthetic COLMAP datasets directly inside Cinema 4D, camera rigs, rendered image sequences, sparse point clouds and camera pose files, with no manual export or reformatting, so you can prototype and test Gaussian Splat and NeRF reconstructions on controlled 3D geometry and skip the physical photo capture stage entirely. The exported folder drops straight into tools like nerfstudio or instant-ngp, and surface normal visibility filtering removes backfacing geometry so the synthetic captures behave more like real photographs.

It is a downloadable piece of software and pipeline tooling, offered free on GitHub, Gumroad and directly from this site, built in Python with the Cinema 4D Python SDK and covering camera model mathematics, the COLMAP file format and plugin architecture.
