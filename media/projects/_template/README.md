# Project Template

Starter files for a new project. The full recipe — required files, the
`detail.md` field reference, the image pipeline, registering the project —
lives in [CLAUDE.md](../../../CLAUDE.md) at the repo root. This folder is
just something to copy so you don't start from a blank file.

```
cp -r media/projects/_template media/projects/your-project-slug
```

Then follow [CLAUDE.md](../../../CLAUDE.md)'s "Adding a new project" section.
