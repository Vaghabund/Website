Txt2Mesh is a text-to-3D tool from 2026: type a plain text prompt and get a finished, textured 3D mesh back inside the software you already work in, with no manual export or import. It ships as two plugins that share one backend, a Cinema 4D plugin written in Python and an Unreal Engine 5.7 plugin built as a native compiled C++ panel with a hand-built Slate interface. Type a subject, optionally attach a reference image, hit render, and the mesh appears already placed in the scene.

Each request is compiled into a ComfyUI workflow: a language model expands the prompt, a text-to-image pass renders an image, and Hunyuan3D 2.1 reconstructs that image into a mesh, with automatic cleanup, hole filling and smoothing. Three modes trade speed for fidelity, a fast geometry blockout, a UV unwrapped PBR textured pass, and an upscaled hero asset pass.
