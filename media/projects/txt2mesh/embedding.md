A cross-engine generative pipeline that lets an artist type a text prompt and receive a finished, textured 3D mesh directly inside their DCC application, with no manual export or import step. Built as two independently maintained plugins sharing one backend contract: a Cinema 4D Python plugin and a native C++ Unreal Engine 5.7 plugin with a hand-built Slate interface. Each request is compiled into a ComfyUI workflow: LLM-based prompt expansion, text-to-image diffusion, then Hunyuan3D image-to-mesh reconstruction, with automatic mesh cleanup, hole-filling, and smoothing. Three quality modes (geometry-only, PBR-textured, upscaled hero-asset) trade render time for fidelity. Renders can run on a locally managed ComfyUI instance, a shared always-on GPU render server, or a Deadline render-farm submission path.

Covers Cinema 4D Python SDK plugin development, Unreal Engine C++ module and Slate UI authoring, Python-to-C++ bridging via the Unreal Python scripting plugin, ComfyUI workflow graph automation and node-graph scripting, generative AI pipeline design, asset library automation with searchable metadata, render job orchestration and queueing, and cross-engine backend architecture. Engineering pivot: discovering Unreal's UMG/Editor Utility Widget tools cannot be authored headlessly from Python, and rebuilding the front end as a compiled native panel instead of forcing an unreliable workaround.
