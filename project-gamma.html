Project Gamma

Mobile App · 2023

Overview

A cross-platform fitness companion that blends tracking, coaching, and habit loops. The product shipped with offline-first sync and personalized workout plans derived from on-device activity data.

Challenge

Deliver real-time recommendations without exposing personal health data to servers.

Solution

Implemented federated learning on-device, paired with end-to-end encrypted backups. The UI surfaces only the signals users need: readiness scores, suggested sessions, and short summaries.

Role

Mobile developer & ML engineer

Timeline

8 months

Technologies

  • React Native
  • TensorFlow Lite
  • Firebase
  • HealthKit / Google Fit
